# Code Reuse

Use this skill when the task is about duplication, shared utilities, or extracting stable abstractions.

## Rules

1. Reuse existing patterns before creating new abstractions.
2. Extract only when duplication is real and behavior aligns.
3. Keep ownership boundaries clear so shared code does not become a dumping ground.
